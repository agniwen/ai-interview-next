# 候选人查重与重复投递

候选人、简历、应聘和面试之间的关系，以及归属更正流程，见 [ATS 设计决策](../adr/0004-ats-candidates-resumes-and-applications.md)。

候选人查重的范围是当前工作区。同一份 PDF 或相同的候选人手机号可以识别已有候选人。两者分别命中不同候选人时，本次提交的候选人按手机号匹配结果确定。

手机号可以从简历中提取。只使用明确属于候选人的手机号，并统一国家区号和号码格式。只有邮箱相同或履历语义相似时，系统照常接收投递，招聘人员可以查看简历。发送面试邀请前，招聘人员须选择关联已有候选人或新建候选人。

如果手机号匹配候选人 B，而相同 PDF 已经归在候选人 A 名下，本次应聘归 B，原简历继续归 A。招聘人员确认后，这份 PDF 才能用于 B 的本次面试。同一 PDF 后续仍匹配 A，只有招聘人员明确纠正 PDF 的查重归属后，后续上传才按纠正后的归属匹配。

如果 PDF 匹配候选人 A，而手机号未匹配到任何候选人，本次应聘归 A。招聘人员确认新号码后才更新 A 的联系方式。确认换号后，只有新号码用于自动匹配，旧号码留在联系方式历史中。

候选人再次投递同一岗位时，如果已有进行中的应聘记录，将本次提交关联到该记录并延续现有面试进度。上一次应聘已结束时，可以创建新的应聘记录并保留历史结果。投递另一个岗位时，为该岗位建立独立的应聘记录。
