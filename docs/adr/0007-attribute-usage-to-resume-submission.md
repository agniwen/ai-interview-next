# 按实际采用的简历上传记录归属用量

同一工作区内，重复文件照常上传并独立处理，上传记录标记文件重复。每次上传都有独立的上传人和处理结果。简历相关处理产生的用量归到本次采用的上传记录对应的上传人，个人中心按当前工作区展示本人用量。

从简历进入招聘流程时绑定所用的上传记录。岗位评价采用该材料，真人面试与 AI 面试在创建轮次时沿用招聘流程的简历，正式开始时保存本轮材料快照。

第一版逐次记录业务阶段、供应商、模型、实际用量和调用结果。阶段用量与总用量从明细按计量单位汇总，缓存命中的输入 token 属于输入 token。失败调用的实际用量单列为重试用量，即使之后没有再次尝试也计入。成功的后续调用计入正常用量，同一次调用结果重复送达只记一次。
