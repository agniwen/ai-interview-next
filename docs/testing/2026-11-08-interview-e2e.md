## 发现与修改

1. 收尾重写过度概括，遗漏 MySQL、回滚、重试等具体事实：明确逐点保留名称、数值、实现、错误处理和更正。
2. 收尾模型混用面试官复述作为候选人引文，导致整个采集点未关联：用原生结构化输出将 `sourceIds` 限制为已保存的候选人片段，程序生成原文证据；不允许生成面试官来源 ID。
3. 实时引文把逗号位置补成句号，导致已回答内容一直 pending：明确引用连续子串、不补标点，并在 pending 时读取原文修正；针对同一场景连续重复验证。
4. 提前结束偶发被标为拒答：在收尾指令和结构化字段说明中区分会话控制与拒绝披露具体信息；所有发现该问题的轮次保留在下表中。
5. 一次语音断言将“三千两百”误判为缺少“3200”：修正为接受等价数值表达，保留原失败记录与复核结论。

## 费用计算

Realtime 每百万 token：文本输入 $4、缓存 $0.40、输出 $24；音频输入 $32、缓存 $0.40、输出 $64。收尾模型每百万 token：输入 $0.75、缓存 $0.075、输出 $4.50。转写使用供应商返回的秒数 × $0.0045/分钟。未把两种模型的 token 混在一起计费。

价格核对日期为 2026-11-08，来源：[OpenAI 价格](https://developers.openai.com/api/docs/pricing)、[GPT-5.4 mini](https://developers.openai.com/api/docs/models/gpt-5.4-mini)。用量通过 [LiveKit Session usage/metrics](https://docs.livekit.io/testing/observability/data/) 采集。首次成功语音轮原测试按输入文件时长估算转写费用，此报告已使用其旁路记录中的供应商转写秒数重算，同时 JSON 明细保留原报告金额。

本地 worker 没有 LiveKit 云托管 Agent 费用，但仍使用 Cloud 的 WebRTC 传输、Voice Focus 增强和会话记录。实际增量取决于套餐、剩余额度及录制配置；[LiveKit 价格](https://livekit.io/pricing) 不能单独确定这次账户扣费，因此记为待账单核对。模型连接超时的那轮没有收到模型计量事件，记录为已观测模型费用 $0，不能据此声称整轮云服务免费。
